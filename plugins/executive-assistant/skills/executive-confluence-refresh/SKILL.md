# Executive Confluence Refresh

Treat Confluence as the curated shared layer, not the working notebook.

## Workflow

1. Identify the target Confluence space, root page, and intended audience.
2. Pull source material from reviewed vault notes, project pages, decisions, or action summaries.
3. Draft concise, shareable content with sensitive material removed.
4. Show the proposed page/update before publishing.
5. Publish through `confluence-cli` only after explicit user approval.

## Output

Prefer a draft with title, purpose, audience, source notes, proposed body, and open questions.
