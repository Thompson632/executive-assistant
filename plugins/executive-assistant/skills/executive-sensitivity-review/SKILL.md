# Executive Check Notes Before Sharing

Help separate shareable operating notes from private historical or sensitive material.

## Review Heuristics

Flag content that contains:

- personal relationship scoring or political commentary
- private stakeholder intelligence
- sensitive personnel details
- raw email content or non-portable Outlook identifiers
- credentials, tokens, or local-only paths
- outdated strategy that could confuse a shared operating model

## Workflow

1. Inventory candidate files before recommending moves.
2. Classify each item as shareable, needs redaction, private archive, or delete candidate.
3. Prefer archiving over deleting when historical value remains.
4. Do not move or delete files until the user approves the reviewed list.
5. Leave shared notes focused on initiatives, meetings, decisions, actions, references, and operating docs.
