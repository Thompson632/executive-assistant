# Executive Assistant Home

Use this vault as the working notebook for meetings, actions, decisions, initiatives, drafts, and reference material.

## Start Here

Add a task to `Action-Items.md`, then ask Codex “Use
`$executive-daily-brief` to preview today's brief.” Ask to save it when you're
ready and open the result in `_briefings/`.

- Review [[Action-Items]].
- Open [[One-on-Ones]] for meeting notes and next-meeting prep.
- Review the latest briefing under `_briefings/`.
- Capture new notes in `tasks/00-Inbox/` or `notes/`.
- Promote durable work into `projects/`, `meetings/`, or curated Confluence pages.
